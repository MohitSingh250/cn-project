## A4. Describe the specific OSI layers in play when running the `ping` command.

1. **Physical Layer (L1):** The Wi-Fi radio translates the data into wireless signals and transmits them over the air.
2. **Data Link Layer (L2):** The 802.11 (Wi-Fi) frame addresses the packets using MAC addresses.
3. **Network Layer (L3):** IP routes the packet based on the destination IP address. ICMP (Internet Control Message Protocol) generates the Echo Request and Echo Reply messages that `ping` relies on.
