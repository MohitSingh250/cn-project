# Evaluation Form Answers: Section B (Private DNS)

---

## B1. What DNS software did you choose and why?

We chose **`dnsmasq`**.
- **Reasoning:** It is extremely lightweight, easy to install via Homebrew, and requires only a single configuration file. It perfectly serves our need to override specific `.test` domains for the local network while forwarding everything else to a public resolver (Google DNS 8.8.8.8).

---

## B2. Show the dig command output that proves the custom domain resolves to the correct internal IP.

Command executed from Mac 2:
```bash
dig @10.7.18.72 app.team1.test
```

Output excerpt:
```
;; ANSWER SECTION:
app.team1.test.     0    IN    A    10.7.10.115
```
This proves the domain correctly resolves to Mac 2, where nginx is running.

---

## B3. Show the dig command output that proves the domain does not exist on the public internet.

Command executed from Mac 2:
```bash
dig @8.8.8.8 app.team1.test
```

Output excerpt:
```
;; ->>HEADER<<- opcode: QUERY, status: NXDOMAIN, id: 54101
```
This proves the domain is completely private, as Google's public DNS returns `NXDOMAIN` (Non-Existent Domain).
