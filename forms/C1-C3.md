# Evaluation Form Answers: Section C (Web Server & Reverse Proxy)

---

## C1. What web server software did you use and why?

We used **`nginx`**.
- **Reasoning:** It is the industry standard for reverse proxying and load balancing. It has native support for TLS termination, round-robin load balancing out of the box, and exceptional performance under concurrent loads.

---

## C2. Show the relevant configuration block that defines the reverse proxy routing.

From `nginx.conf`:
```nginx
location / {
    proxy_pass http://backends;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

---

## C3. Demonstrate the load balancer distributing traffic across two backends.

We ran a script to execute 6 consecutive requests:
```bash
for i in {1..6}; do curl -s -D - https://app.team1.test/api/status | grep "X-Backend"; done
```

**Output:**
```
X-Backend: B
X-Backend: A
X-Backend: B
X-Backend: A
X-Backend: B
X-Backend: A
```

This perfectly alternating sequence demonstrates nginx's default round-robin load balancing distributing traffic evenly across both our Node.js backends.
